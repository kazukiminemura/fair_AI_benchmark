測定条件・メモリ帯域

CPUとGPUは別の負荷で測定します。GPUは大きな行列をGPU内で連続計算し、まとめて完了を待ちます。準備と結果の読戻しは測定区間から除き、測定前後に全出力をCPU参照計算と照合します。TFLOPSは完了した演算数と実時間からの換算値です。

ブラウザの実装・省電力・発熱・他のアプリの影響を含みます。v1の測定値・PC用ONNX測定・メーカーの理論値とは直接比較できません。GPU経路はソフトウェア描画の場合もあります。

メモリ帯域はTypedArrayコピーの読出し＋書込みの実測です。キャッシュの影響を含み、DRAMの理論帯域・NPU専用帯域ではありません。メモリのバス幅はブラウザから取得できません。

スマホから開く方法
  1. PCで fairbench serve --mobile --port 8768 を起動します。ソース版は先頭に uv run を付けます。
  2. スマホをPCと同じWi-Fiに接続します。
  3. PCに表示された http://…:8768/mobile をスマホのブラウザで開きます。

接続できない場合は、PCのプライベートネットワークでアプリの通信が許可されているか確認してください。結果はこのブラウザ内に保存され、PCには送信しません。

最後の結果をこのブラウザに保存します。同じ測定バージョン・同じ負荷同士で比較してください。CPUとGPUの倍率比較はできません。
